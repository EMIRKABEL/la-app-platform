# Backend

The **Backend** service is built with **FastAPI** (Python) and provides:

- REST API for content management
- REST API for student interaction and progress tracking
- Authentication and authorization
- PostgreSQL database integration

## Tech Stack

- FastAPI (Python 3.11+)
- PostgreSQL 16
- SQLAlchemy / Alembic (planned)
