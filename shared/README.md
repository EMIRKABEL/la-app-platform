# Shared

This folder contains **schemas, types, and contracts** shared across all services in the LA App platform:

- API request/response models
- Data transfer objects (DTOs)
- Shared enums and constants
- Validation schemas (JSON Schema, Pydantic, Zod, etc.)

## Structure (planned)

```
shared/
├── schemas/       # API contracts and data models
├── types/         # TypeScript type definitions
├── constants/     # Shared constants and enums
└── README.md
```

## Status

This folder is currently a placeholder. Shared contracts will be added as services are built.
